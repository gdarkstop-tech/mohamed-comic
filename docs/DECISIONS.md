# Architecture decisions

## D1. Provider-independent core, Cloudflare first
The pipeline only depends on the `ImageProvider` protocol
(`weaver/providers/base.py`). Cloudflare Workers AI is the first implementation.
Another backend means one new module plus one `provider.name` value in
`weaver.yaml`.

**Cloudflare contract used** (developers.cloudflare.com, checked 2026-10-21):
`POST /client/v4/accounts/{id}/ai/run/@cf/black-forest-labs/flux-2-klein-4b`,
multipart form fields `prompt`, `width`/`height` (256–1920), `seed`, `guidance`,
`input_image_0..3` (each ≤512×512). Steps are fixed at 4. Response
`result.image` is base64. Errors that matter: 3036/429 daily allocation used
(stop), 3040/429 capacity (retry with backoff), 5035/403 paid plan required
(stop), 401/403 auth.

## D2. Free-tier enforcement is deterministic, not advisory
* `daily_neuron_cap` (9,000) must be ≤ `free_allocation` (10,000) or the config
  is rejected.
* Each request's cost is estimated from the published rates (26.05 neurons per
  output 512² tile, 5.37 per input tile, tiles rounded **up**) and checked
  against `max(local ledger, Cloudflare-reported usage + local spend since)`.
* Timeouts and dropped connections are charged as if billed, because the
  provider may have done the work.
* A 3036 response marks the UTC day exhausted; nothing runs until 00:00 UTC.
* A run lock stops two runs from spending the same budget.
So even if the account were moved to Workers Paid, this tool cannot cause
billable overage.

## D3. Lettering is never generated by the model
The prompt forbids text. Balloons, captions and SFX are drawn by `balloons.py`
with OFL fonts (Comic Neue, Bangers). Text stays correctly spelled and can be
edited (or translated later, including Arabic/RTL) without regenerating art.

## D4. Identity references: real photos beat artwork
Each character lists references in priority order. The first available identity
reference is sent; photos (`kind: photo`) outrank approved art. Spare slots go
to the house-style anchor, then setting, then outfit references. The prompt
numbers images exactly as sent (`input_image_0` = "image 0").

## D5. State, versions and locks
`production.json` records every version (seed, prompt hash, reference hashes,
cost) and is written atomically after each panel. Locking stores the artwork's
SHA-256; compose refuses locked art that changed on disk. An append-only JSONL
audit log records every provider call and its outcome.

## D6. Privacy by default
The GitHub repository is public and the material shows real people. All images
and outputs live in git-ignored `private/`. Committed files hold only
coordinates, names and descriptions. Consequence: in an ephemeral cloud session
`private/` is lost when the container is reclaimed. Fix: make the repo private
(then outputs may be committed), or run Claude Code on the author's computer.

## D7. Fallback providers (not implemented)
No Cloudflare documentation marks FLUX.2 [klein] 4B as Workers Paid only (the
July 2026 paid-only change named three LLMs). The live test settles it. Only if
it fails on the Free plan, evaluate in order:
Hugging Face ZeroGPU Spaces (FLUX.2 klein demos) and a Kaggle notebook running
the open 4B weights on the free GPU allowance. Quotas must be confirmed at that
time. One account per service, no quota evasion.
